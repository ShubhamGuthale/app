# 📓 Personal Journal Application – Backend API (Spring Boot)

A secure and scalable backend service for a **Personal Journal Web Application**, built with **Java Spring Boot**. This RESTful API allows users to register, authenticate, and perform CRUD operations on journal entries. Designed with modular architecture, clean code practices, and industry-standard security mechanisms.

---

## ✅ Core Features

- 👤 **User Management**
  - User registration, login, and role-based access
  - Secure password encryption using BCrypt
- 📝 **Journal Management**
  - Create, read, update, and delete personal journal entries
  - Timestamped entries with user mapping
- 🔐 **Authentication & Security**
  - JWT-based authentication and authorization
  - Spring Security integration
- 🧪 **RESTful APIs**
  - Built using REST principles with clear request/response formats
  - Error handling with global exception handlers
- 🌐 **Cross-Origin Support**
  - Configured for integration with frontend frameworks (React, Angular, etc.)
